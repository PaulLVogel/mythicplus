# Mythic+ Mechanic Refresher

Static web app for **World of Warcraft: Midnight Season 2** (Patch 12.1, Curse of Ula'tek).

Open a dungeon, skim each boss by role, and search a mechanic before the key.

## Stack

Plain HTML, CSS, and JavaScript. No build step. Deploys on Vercel as a static site.

## Local

Open `index.html` in a browser, or:

```bash
npx serve .
```
